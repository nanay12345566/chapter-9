Chapter 9 — Capital Budgeting

NPV · IRR · Payback · PI · Built only from Dr. White's packet · Manual + BAII Plus

The Big Idea (plain English)

A project is any investment the firm can make (new machine, new product, new store). Capital budgeting is just deciding which projects to accept or reject.

The whole chapter answers one question: will this project make us richer? We have four tools to judge that. Each tool gives a number and a simple accept/reject rule.

The four tools at a glance

1. NPV — Net Present Value the BEST rule

Take every future cash flow, discount it back to today, add them all up, subtract the cost. What's left is profit in today's dollars.

NPV = CF₀ + CF₁/(1+r) + CF₂/(1+r)² + ... + CFₙ/(1+r)ⁿ

CF₀ is the cost (negative). r = cost of capital (discount rate). It's the BEST rule because it shows exactly how much shareholder wealth is added.

Rule: NPV > 0 → accept. NPV < 0 → reject.

2. IRR — Internal Rate of Return most popular

The one discount rate that makes NPV exactly zero. It's the project's built-in percentage return.

IRR is the rate r where NPV = 0

When cost of capital = IRR, NPV = 0 (breakeven). Managers LOVE it because it's a %, but it can be overly optimistic.

Rule: IRR > cost of capital → accept. IRR < cost of capital → reject.

3. Payback Period

How many years until the cash flows add back up to the original cost.

Payback = full years + (unrecovered cost ÷ next year's cash flow)

Weakness: ignores time value of money and anything after payback. Quick gut-check only.

Rule: Payback < the firm's cutoff → accept.

4. PI — Profitability Index

The ratio of benefits to costs: PV of the inflows divided by the initial cost.

PI = (PV of future cash inflows) ÷ (initial cost)

PI = 1 + (NPV ÷ cost). If you already have NPV, PI is one step away.

Rule: PI > 1 → accept. PI < 1 → reject.

Why they all agree (usually)

For a single normal project, all four rules give the same accept/reject answer. That's your sanity check: if NPV says accept, IRR should beat the cost of capital and PI should exceed 1.

  • NPV > 0 ⟺ IRR > r ⟺ PI > 1

Common traps in this packet

  • Entering the cost (Year 0) as a positive number. It's an outflow → negative.
  • Comparing IRR to zero. Compare it to the cost of capital.
  • Forgetting to clear cash-flow registers between projects: 2ND → CE|C (CF, 2ND, CLR WORK).
  • Using PI rule "greater than 0." The PI cutoff is 1, not 0.
  • Payback: stopping at the whole year instead of taking the fraction of the final year.

Memory tricks

  • NPV = "New Profit in dollars, Value today." Best rule.
  • IRR = "I Really Return this %." Beat the cost of capital.
  • PI > 1 = "Positive Investment." The cutoff is one.
  • "We LOVE %%%" — that's why IRR is popular even though NPV is better.

Review-question answers (packet fill-ins)

  • Best measure of dollar profit = NPV. Different from normal profit because it considers time value of money. Accept if NPV > 0, reject if NPV < 0.
  • Best measure of % return = IRR. When WACC = IRR, NPV = 0. Accept if IRR > WACC, reject if IRR < WACC.
  • Best measure of how quickly cost is recovered = payback. Accept if payback < cutoff.
  • Ratio of benefits to costs = PI. Accept if PI > 1, reject if PI < 1.
  • BEST rule = NPV (adds to shareholder wealth). Most popular = IRR (we love %%%).
